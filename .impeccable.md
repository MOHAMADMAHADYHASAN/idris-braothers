# `.impeccable.md` — Design Context & Anti-Slop Standards

## 1. Product & Target Users
- **Product:** ইদ্রিস ব্রাদার্স — Grocery, Spice & Wholesale/Retail POS, Multi-Unit Inventory & Running Khata ERP (`idris-brothers`).
- **Location & Store Profile:** Morichpotti, Feni Bazar, Feni, Bangladesh.
- **Primary Users:** Store owners and counter cashiers operating 10–12 hours/day (high-speed barcode/reverse-weight POS billing, mohajan challan entry, customer due collection, daily cashbox reconciliation, thermal receipt & barcode sticker printing).
- **Language & Numerals:** Bangla-first interface (`Noto Sans Bengali`), strict tabular Bangla numerals (`bn-BD` via `src/lib/decimal.ts` + `JetBrains Mono`) everywhere in UI except `<input type="number">`, ISO API dates, Code128 SVG barcodes, and ESC/POS thermal ASCII bytes.

## 2. Aesthetic Direction & Anti-Slop Principles
- **Authoritative Counter Craft (Not Generic AI SaaS):**
  - Clean, flat-to-micro-elevated paper surfaces (`--surface-canvas` / `--surface-card`) designed for low eye-strain over 10–12 hour counter shifts.
  - **Strict Ban on AI Slop:** Never use purple/indigo/violet gradients, rainbow pastel icon grids on navigation cards, glassmorphic sticky headers (`backdrop-blur-*`), or competing dark `bg-slate-900` CTAs.
- **Semantic Color Discipline:**
  - **Brand Primary (Navy):** `--color-brand-deep` (`#1e4a7a`) for navigation, primary CTAs, focus rings, and neutral operational structure.
  - **Cash / Paid / Profit:** `--color-cash-*` / `--color-success` (Emerald semantic tokens only).
  - **Due / Payable / Wastage / Destructive:** `--color-due-*` / `--color-danger` (Rose semantic tokens only).
  - **Wholesale / Bulk / Stock Alert:** `--color-wholesale-*` (Strictly Amber — never indigo/purple).
- **Theming:** Intentional **Daylight Light Theme Only** (`--color-surface-canvas: #f8fafc`, `--color-surface-card: #fcfdff`) optimized for bright grocery counter operations (`src/app/globals.css`), with `@media print` switching to `#ffffff` paper and `#000000` ink for 58mm/80mm thermal receipts and Code128 barcode stickers.

## 3. Accessibility, Touch & Motion Standards
- **Dialogs & Drawers:** Every modal and drawer uses `useDialogAccessibility` (`role="dialog"` / `role="alertdialog"`, `aria-modal="true"`, `aria-labelledby`, `Escape`-to-close, focus trap, scroll lock, focus restoration).
- **In-App Feedback:** Zero native `alert()`/`confirm()`. All user notifications and confirmations go through `toast` and `confirmAction` (`src/lib/feedback.ts` + `src/components/shared/AppProviders.tsx`).
- **Forms & Controls:** Explicit `<label htmlFor>` + `id` via `useId()`, `aria-label` on all icon-only buttons/links, single DOM tree in `/pos` (no duplicate IDs), and `min-h-10` / `w-10 h-10` counter touch targets on POS steppers and modal close buttons.
- **Motion:** Root `<MotionConfig reducedMotion="user">` plus `@media (prefers-reduced-motion: reduce)` CSS guards.

## 4. Intentional Hardware/Thermal Exceptions
- `ThermalReceipt.tsx`, `CashboxClosingReceipt.tsx`, `ProductProfile360Client.tsx` (`50mm × 30mm` print-only thermal sticker sheet), and `StoreShutterHero.tsx` preserve physical thermal roll typography (`9px–11px`), `#000000`/`#ffffff` print high-contrast, or steel shutter landing overlay styling intentionally.
